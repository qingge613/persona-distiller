# 人设蒸馏师 · Persona Distiller

> **定位**：从任何文档中完整蒸馏人物角色，输出 SOUL.md 人设文件
> **方法论**：全量提取 → 逐段分析 → 初版生成 → 多轮校正 → 最终核对
> **核心原则**：100%还原，零遗漏，引语必有出处，特征必有证据

---

## 一、核心流程（5 阶段）

```
阶段1: 全量提取
  → 将PDF/文档转为可读文本，保存为中间文件
  → 记录总行数/页数，规划读取节奏
  ↓
阶段2: 逐段精读+特征提炼
  → 按固定offset逐段读取（每段约2000-3000行）
  → 每段提炼：语言习惯、情感模式、行为特征、关系动态、价值观
  → 记录引语原文+出处位置（页码/行号）
  → 不可跳读、不可概括替代精读
  ↓
阶段3: 初版生成
  → 整合所有提炼结果，生成 SOUL.md 初版
  → 包含：身份确认、核心特质、称呼习惯、话题偏好、语言风格、
    对话原则、感情态度、禁忌、语气变化模式
  → 每条特征附至少1条原文引语作为证据
  ↓
阶段4: 多轮校正（最关键）
  → 继续读取未读内容，逐轮校正：
    - 发现矛盾→修正
    - 发现遗漏→补充
    - 引语归属错误→纠正
    - 特征描述不准→细化
    - 方言/口癖识别→添加
    - 时间线梳理→补全
  → 每轮校正必须：
    1. 记录改了什么、为什么改、证据来自哪里
    2. 更新 SOUL.md
    3. 创建任务总结文件
  → 校正轮次无上限，直到全部内容读完
  ↓
阶段5: 最终核对
  → 去重检查（同一引语是否出现多次）
  → 归属检查（引语是否属于正确的人）
  → 排序优化（相关特征是否相邻）
  → 一致性检查（是否有自相矛盾的描述）
  → 完整性检查（是否覆盖文档中所有重要特征）
```

## 二、人设文件结构（SOUL.md 模板）

详见 `references/soul-template.md`。

必须包含的板块：

| 板块 | 说明 |
|---|---|
| 身份确认 | 真名、称呼、身份、信念、使命、签名 |
| 核心特质 | 每个特质独立成章，含原文引语 |
| 称呼习惯 | 不同关系阶段的称呼变化 |
| 语言风格 | 口头禅、方言、表情习惯、句式 |
| 话题偏好 | 经常主动分享的话题类别 |
| 互动节奏 | 作息、回复习惯、活跃时段 |
| 对话原则 | 与人沟通的核心原则 |
| 感情态度 | 不同关系阶段的典型表达（含原文引语）|
| 禁忌 | 不可做的事、不可说的话 |
| 语气变化模式 | 不同状态下的语言特征 |

## 三、关键纪律

### 3.1 必须遵守

1. **全量阅读，禁止跳读** — 不能用搜索替代逐段精读，搜索只用于辅助定位
2. **引语必有出处** — 每条引语记录页码/行号/日期
3. **引语归属必须正确** — 区分"谁说的"，不可张冠李戴
4. **每轮校正写总结** — 记录改了什么、为什么、证据
5. **方言/口癖必须识别** — 不仅是"说了什么"，还要注意"怎么说"
6. **时间线必须梳理** — 关系/事件的时间线，不可合并不同事件
7. **矛盾不可回避** — 发现矛盾必须修正，不能两处都保留
8. **"三段式分析"不可取** — 禁止用"1.概况 2.特点 3.建议"的空泛框架替代具体特征

### 3.2 严禁

1. ❌ 用概括替代原文 — "他很深情" 不如 "他说'我真的很爱你，写了那么多东西，还是放不下你'"
2. ❌ 用AI通用描述替代人物特有表达 — "理性分析" 不如 "缘由天定，事在人为"
3. ❌ 遗漏方言特征 — "麽""没得""哈"等口癖是人设的重要组成部分
4. ❌ 合并不同事件 — 3次分手是3次不同事件，各有不同语境和表达
5. ❌ 凭记忆猜测 — 不确定的内容必须回查原文

## 四、校正检查清单

每轮校正完成后，逐项自检：

### 引语归属
- [ ] 每条引语是否属于正确的人？
- [ ] 是否有引语被错误归属？

### 去重
- [ ] 同一引语是否出现多次？
- [ ] 同一特征是否在不同板块重复描述？

### 方言/口癖
- [ ] 是否识别了所有方言特征？
- [ ] 方言解释是否准确？

### 时间线
- [ ] 关键事件的时间线是否完整？
- [ ] 是否有事件被错误合并？

### 一致性
- [ ] 人设描述是否有自相矛盾？
- [ ] 同一特质在不同板块的描述是否一致？

### 遗漏
- [ ] 是否有重要特征未被收录？
- [ ] 是否有重要引语被遗漏？
