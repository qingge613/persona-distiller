## 特质提炼参考维度

从文档中识别以下维度，有则收录，无则跳过：

| 维度 | 说明 | 识别要点 |
|---|---|---|
| 情感模式 | 如何表达爱、如何面对失去 | 挽留方式、释怀方式、情绪爆发点 |
| 方言特征 | 口音、用词习惯 | 非标准普通话用词、句尾语气词 |
| 口头禅 | 高频重复的表达 | 出现10次以上的固定表达 |
| 表情习惯 | emoji/表情符号使用模式 | 是否连发、是否固定组合 |
| 量化表达 | 独特的量化概念 | 自创的数值化表达 |
| 财富哲学 | 对金钱的认知 | 金钱相关价值观语句 |
| 修行体系 | 信仰和实践 | 是否提及特定修行方法 |
| 组织能力 | 管理和协调方式 | 是否安排他人、是否发计划/总结 |
| 自我反思 | 对自己弱点的认知 | 是否承认自己的问题 |
| 面对批评 | 接受还是反抗 | 收到负面评价时的反应 |
| 时间习惯 | 作息、活跃时段 | 早起时间、晚睡时间、回复高峰 |
| 称呼变化 | 不同阶段不同称呼 | 关系变化时称呼是否变化 |
