# 校正方法论 — 从实战中提炼

> 本文件记录人设蒸馏过程中最易犯的错误和校正方法。
> 基于超长文档多轮修正的实战经验总结。

---

## 一、最易犯的5个错误

### 错误1：用AI通用描述替代人物特有表达
- ❌ "理性分析" → ✅ 使用人物自己的原话
- ❌ "情感克制" → ✅ 使用人物对自己状态的描述
- ❌ "关心他人" → ✅ 引用人物关心他人的具体语句
- **校正方法**：每条特征必须附原文引语，不可只用概括词

### 错误2：引语归属错误
- 多人对话中，A说的话被错误归给B
- 尤其在聊天记录中，发言人和引用内容容易混淆
- **校正方法**：区分"谁说的"，文档中多人对话必须标注说话人

### 错误3：遗漏方言特征
- 非标准用词可能是方言，不是打字错误
- 句尾语气词是身份标识
- 情绪爆发时的方言最具辨识度
- **校正方法**：精读时专门标注方言用词，不要当作打字错误忽略

### 错误4：合并不同事件
- 相似主题的不同事件各有不同语境
- 多次分手/冲突是独立事件，不可混为一谈
- **校正方法**：梳理完整时间线，每个事件独立记录

### 错误5：过早定型
- 初版往往只反映前30%内容的特征
- 后70%可能推翻或深化初版认知
- 例：初版写"情感克制"→后70%内容揭示"深情执着"
- **校正方法**：必须读完全部内容才能定稿

## 二、校正轮次规范

每轮校正必须包含：

```
### 第N轮校正

**读取范围**：第X页-第Y页（offset AAAA-BBBB）

**新发现**：
1. {发现1} — 证据：第ZZZ页，原文"..."
2. {发现2} — 证据：...

**修正内容**：
1. {修正1}：原文写"{旧}"，改为"{新}" — 原因：...
2. {修正2}：...

**新增内容**：
1. {新增1}：{内容} — 依据：...
```

## 三、时间线梳理方法

1. 按时间顺序标记所有关键事件
2. 每个事件记录：日期、触发方、核心表达、结果
3. 不同事件不可合并，即使主题相似
4. 时间线示例格式：

```
- YYYY年MM月DD日：事件1描述（触发方）
- YYYY年MM月DD日：事件2描述（触发方）
- YYYY年MM月DD日：事件3描述（触发方）
```

## 四、方言识别指南

| 现象 | 可能的方言区 | 注意事项 |
|---|---|---|
| 句尾"麽"代"吗" | 西南官话区 | 不是打字错误 |
| "没得"代"没有" | 西南官话区 | 口语化表达 |
| "咱们"代"我们" | 北方/亲密表达 | 表达亲密时使用 |
| 句尾"哈" | 西南/四川 | 语气词，表亲切 |
| "锤子"表否定 | 四川方言区 | 脏话委婉语，表否定/愤怒 |
| "叼"表厉害 | 南方方言区 | 意为"酷/厉害" |
| "中"表肯定 | 河南 | 意为"好/行" |
| "晓得"代"知道" | 四川/湖南 | 口语化表达 |
| "咋"代"怎么" | 东北/北方 | 口语化表达 |

注意：方言不是"不标准"，是人物身份的重要组成部分。

## 五、引语收集标准

### 必须收录的引语
- 人物的核心信念表达
- 人物的自我认知陈述
- 不同情绪状态下的典型表达
- 方言/口癖的原文例句
- 关系转折点的关键对话

### 可以不收录的
- 纯事务性确认（"好的"、"嗯嗯"、"好"）
- 不体现人物特质的日常寒暄

### 引语格式
```
"原文引语" — {日期/页码位置}
```

## 六、隐私保护提醒

⚠️ 校正过程中涉及的原文内容可能包含敏感信息。在校正方法论中：

- **引语仅用于人设提炼**，不得泄露给第三方
- **示例数据必须脱敏**后再用于公开文档
- **时间线中不记录具体地址/电话/身份证号**
- **关系人物使用化名**
